# MontanhaJr Android App Portfolio

A lightweight static portfolio for GitHub Pages.

## Deploy

1. Create a repository named `MontanhaJr.github.io` on GitHub.
2. Copy the contents of this folder to the repository.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Your site will be available at `https://montanhajr.github.io`.

## App icons

The site currently looks for:

- `assets/apps/dotpop-icon.png`
- `assets/apps/pet-clicker-icon.png`

If the files are not present, the page automatically shows a fallback placeholder. Add the official 512×512 or 1024×1024 Play Store icons using the filenames above.

## Updating downloads

The download count shown in `index.html` is intentionally static. Google Play displays rounded ranges such as `1K+`, so update the text when your Play Console reaches the next public threshold.
